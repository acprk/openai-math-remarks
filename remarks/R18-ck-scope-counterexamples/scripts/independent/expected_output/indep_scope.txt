Part 2: Taylor expansions in lam (exact)
   I(f;Y)            = ( 1/2 ) lam^2 + O(lam^3)
   psi(lam r)        = ( r**2/2 ) lam^2 + O(lam^4)
   Hellinger loss    = ( 1/(2*sqrt(1 - m**2)) ) lam^2 + O(lam^3)
   1-sqrt(1-lam^2)   = ( 1/2 ) lam^2 + O(lam^4)
   => (A) fails for small lam iff r_m < 1 iff H(m) < log 2 iff m != 0;
      (B) fails for small lam iff 1/sqrt(1-m^2) > 1 iff m != 0.
